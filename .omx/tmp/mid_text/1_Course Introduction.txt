Approaches to Robot Control
• Manual Teaching & Direct Programming
사람이 로봇의 움직임을 직접 가르치거나 프로그래밍하는 방법

• Human-in-the-loop Control (Teleoperation)
사람이 실시간 입력으로 원격 조정하는 방법

• Model-based Planning & Control
로봇과 환경의 물리 법칙(Kinematics, Dynamics)을 수학적 모델로 만들어 경로를 자동 생성하고 제어하는 방법

• Learning-based Planning & Control
데이터를 기반으로 로봇이 스스로 최적의 행동 정책을 학습(RL, Imitation Learning)하는 방법
* 실제 로봇 시스템에서는 여러 방식이 결합되어 사용될 수 있음

Human-in-the-loop Control (Teleoperation)

Human-in-the-loop Control (Teleoperation)
• Human input interface (사람의 조작 방식)
- Joystick/Gamepad, HMD/VR Controller, (Vision or Sensor based) Motion Capture, Haptic Device 등

• Mapping (사람의 입력/의도를 로봇의 실행 명령으로 변환)
- Scaling, Frame Transform, Inverse Kinematics, Redundancy Resolution 등

• Control (사람의 상위명령을 feedback 기반으로 로봇이 실행)
- Low-level Servo, Impedance/Admittance Control, Operational-space control, Trajectory smoothing 등

• Safety & Constraints (로봇 행동의 실시간 안전 제어)
- Joint Limit, Collision Avoidance, Workspace Constraints, Emergency Stop, Force/Torque Threshold

• Perception & Feedback (행동의 결과를 사람에게 전달)
- Vision, Haptic Feedback, Audio Cue 등

• Communication (네트워크/지연/동기화 처리)
- Latency/jitter buffering, Time synchronization, Prediction / dead-reckoning (지연 보상) 등

Robot Models
• Geometric Model
로봇의 외형(shape)과 collision shape를 정의하며, planning과 simulation에서 사용되는 기하학적 모델

• Kinematics Model
Link–Joint 구조와 좌표계 관계를 정의하며, joint space (q)와 task space (x)의 관계를 표현하는 모델

• Dynamics Model
Mass, inertia, gravity, friction 등을 포함하여 force/torque 기반 제어와 물리 시뮬레이션을 위한 모델

Model-based Planning & Control
• Robot의 물리적 특성을 수학적 방정식 (Model)로 정의하고, 이에 기반하여 미래의 상태를 예측하여 최적의
행동 경로를 계산하고 제어하는 방식
𝑀 𝑞 𝑞̈ + 𝑏 𝑞, 𝑞̇ + 𝑔 𝑞 = 𝜏 + 𝐽 (𝑞) 𝐹
𝑀 𝑞 𝑞̈ : Inertia (관성)
𝑏 𝑞, 𝑞̇ : Coriolis/Centrifugal (회전 시 발생하는 힘)
𝑔 𝑞 : Gravity (중력)
𝜏: Actuator torque (관절에 가해지는 토크)
𝐽 (𝑞) 𝐹 : Contact Force (외부 환경과의 접촉에 따른 힘)

• Offline Planning (Trajectory Optimization)
특정 목표(Goal)를 달성하기 위해 미래에 수행할 일련의 동작이나 경로를 생성하는 과정
• Online Control (Model Predictive Control)
Planning에서 생성된 계획을 실제 로봇 하드웨어가 정확하게 따라가도록 만드는 과정

Learning-based Planning & Control
• 시뮬레이션 기반 강화학습 (Reinforcement Learning)
 가상환경에서 수많은 시행착오를 통해 안전하게 학습
 보상함수의 설계가 어려우며, 시뮬레이션과 현실세계의 간극 (Sim2Real)이 큼
• 원격 조종 기반 모방학습 (Imitation Learning)
• 복잡한 작업 수행이 가능하며, 빠르고 쉬운 초기 모델 개발에 유용
• 고품질의 Demonstration 데이터를 필요로 하며, 작업자에 따라 모델의 품질이 크게 달라짐
• 로봇 파운데이션 모델 (Robot Foundation Model)
• Robot AI의 최신 동향으로 LLM의 성공 방정식을 따름
• 다양한 task로의 generalization 가능하여 multi-task / multi-robot / multi-modal 학습 가능
• 데이터 수집이 매우 어렵고, 학습비용 역시 매우 큼

Installation: ROS2
• Install ROS2
https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debs.html
• Install rosdep
$ sudo apt install python3-rosdep
$ sudo rosdep init
$ rosdep update
$ sudo apt update
$ sudo apt dist-upgrade

• Install Colcon the ROS 2 build system with mixin:
$ sudo apt install python3-colcon-common-extensions
$ sudo apt install python3-colcon-mixin
$ colcon mixin add default
https://raw.githubusercontent.com/colcon/colcon-mixinrepository/master/index.yaml
$ colcon mixin update default
