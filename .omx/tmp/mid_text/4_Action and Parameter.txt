Action
• Action은 수행 시간이 긴 tasks (long running task)를 처리하기 위한 ROS2 communication 유형이다.
• Action은 Service와 유사하게 기본적으로는 Server-Client 모델이지만 다음 2가지가 다르다.
- Preemptable: 즉, Action이 수행되는 동안 실행 취소(cancel)이 가능하다.
- Feedback: Action이 수행되는 동안 server는 client에게 feedback을 보낼 수 있다.
• Action은 크게 3개의 구성요소를 갖는다. a goal, feedback, and a result
- Action은 Goal과 Result를 처리하기 위해 Service를 이용하고, Feedback을 처리하기 위해 Topic을 사용한다.

Action
• Action Client는 Action Server에게 Goal을 보내고, Action Server는 이에 대한 응답을 반환한다.
• Action Client는 Action Server에게 Result를 요청한다.
• Action server는 Action을 수행하며 이 과정 중에
Action Client에게 Feedback을 보낸다.
• Action이 완료되면, Action Server는
Action Client에게 Result를 반환한다.

Action Goal States
• Action Server는 Client로부터 요청된 각 Goal에 대해 실행부터 종료까지의 상태를 State Machine으로 유지 관리한다.

서버가 goal을 받아들여 실제 작업을
수행하고 있는 상태

goal이 정상적으로 완료되어,
기대한 결과를 도출한 상태

client로부터 취소 요청에 의해,
서버가 goal의 취소를 진행 중인 상태

goal 실행 중 예기치 않은 오류나
문제로 인해 강제 종료된 상태

Goal이 접수되었으나, 아직
실행이 시작되지 않은 초기 상태

from action_msgs.msg import GoalStatus
result = result_future.result()
status = result.status

goal이 취소 요청에 따라 중단되어,
더 이상 실행되지 않는 상태

Program Action Server with Python
• Tutlesim 로봇을 몇 초간 좌측으로 회전하는 Action Server를 만들어보자.
- Goal 수신
. Action client로부터 Goal은 goal_handle.request로 받고: goal_handle.request.secs: client가 요청한 시간
. Action server가 client의 요청에 따라 수행할 일을 처리할 callback function 등록: execute_callback(goal_handle)
- Goal 실행 (callback function)
. goal_handle.request.secs로 client가 요청한 시간 (seconds)을 읽고
. 그 시간 만큼 /turtle1/cmd_vel Topic에 Twist type message를 publish (linear.x=0.3, angular.z=0.3)
- Feedback 송신
. goal_handle.publish_feedback(feedback)으로 feedback을 Action Client에 전송
- Result 송신: 실행 완료
. goal_handle.succeed()로 성공 처리
. 로봇 정지 및 result.status 반환

def execute_callback(self, goal_handle):
# Create feedback message (self.feedback=Move.feedback())
self.feedback.feedback = "Moving around left left left..."
# Main logic for this Action Server
for i in range(1, goal_handle.request.secs):
self.get_logger().info('Feedback ({}): {} '.format(i, self.feedback.feedback))
# Set the desired velocity values and publish this data
self.cmd.linear.x = 0.3
self.cmd.angular.z = 0.3
self.cmd_vel_publisher.publish(self.cmd)
# Publish the feedback message
goal_handle.publish_feedback(self.feedback)
# Sleep 1 second
time.sleep(1)

Program Action Client with Python
• 사용자로부터 회전 지속 시간(seconds)을 입력 받아 Action Server에 실행을 요청하는 Action Client를 만들어보자.
- 사용자의 입력을 Goal로 변환
- Goal 전송 (비동기 요청)
. Action server에 goal을 요청하고 서버로부터 오는 feedback을 받아서 처리할 feedback callback function을 등록:
send_goal_async(goal, feedback_callback)
. 서버로부터 수락/거절에 대한 결과를 받아서 할 일을 goal callback function으로 등록: add_done_callback(callback)
- Goal 수락/거절 판단
. Action server로부터 반환된 결과가 goal을 수락했는지 거절했는지를 먼저 체크: if not goal_handle.accepted:
. 수락 시 서버의 결과를 받아옴: get_result_async() 호출
. 결과를 받고 해야 할 일을 result callback function으로 등록: add_done_callback(self.result_callback)
- 실행 중 Feedback 수신
. 서버로부터 받은 feedback을 받아서 해야 할 일을 feedback_callback 함수 내에서 수행
- Result 수신: 실행 완료
. 서버 결과를 받아서 처리할 일을 result_callback 함수 내에서 수행 (Result를 처리한 후 프로그램 종료)

self.battery_percentage_warning_ = self.get_parameter("battery_percentage_warning").value
