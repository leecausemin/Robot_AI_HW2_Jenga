Create Link
• Link 하나를 만들고 "base_link"라고 이름을 붙였다.
• Link는 크기가 0.1m, 0.1m, 0.1m인 box 형태를 갖는다.
• URDF 단위
- 길이: meter
- 각도: radian
- 무게: kilogram
• Link Geometry
- box:
<box size="0.05 0.05 0.05"/>
- cylinder: <cylinder radius="0.05" length="0.09"/>
- sphere: <sphere radius="0.05"/>

</geometry>
</visual>
</link>
</robot>

• Link elements
<visual>: Link의 시각화 속성 정보 (원점, 형상, 크기, 색상 등)
<collision>: Link의 물리적인 충돌 속성 정보 (원점, 형상, 크기, 색상 등)
<inertial>: Link 관련 관성 정보 (관성중심, 질량, 관성계수 등)

Create Joint
• Joint를 구성하는 기본 요소는 다음과 같다.
- Parent and Child Link: Joint에 2개의 Link가 어떻게 연결되었는지를 알려준다.
여기서는 parent_link가 "base_link"이고 child_link가 "head_link"이다.
<parent link="base_link" />
<child link="head_link" />

- Origin: Joint는 roll, pitch, yaw의 회전 운동을 하고, x, y, z로 직선 운동을 한다.
이 때 Joint의 좌표는 parent_link의 좌표가 reference가 된다.
<origin rpy="0 0 0" xyz="0 0 0.11" />

이 경우, Joint의 origin frame은 "base_link" origin frame을 기준으로 z방향으로 0.11m 떨어진 위치가 된다.

Joint Types
• ROS2는 다음과 같은 Joint type을 지원한다.
- revolute (예: robot arm)
- prismatic (예: robot head)
- continuous (예: robot wheel)
- fixed (예: robot base)
<joint name="base_link_to_head_link_joint" type="continuous">
<origin rpy="0 0 0" xyz="0 0 0.11" />
<parent link="base_link" />
<child link="head_link" />
</joint>
<joint name="base_link_to_head_link_joint" type="revolute">

<child link="head_link" />
</joint>

<parent link="base_link" />
<child link="head_link" />
</joint>

Move the Joints
• continuous type은 -360도에서 360까지 완전히 회전을 하는 joint이고, revolute type은 회전에 limit을 갖는 joint이다.
• effort(force 또는 torque), (angular) velocity를 지정하고 angle 또는 distance에 limit을 줄 수 있다.
<joint name="base_link_to_head_link_joint" type="revolute">
<origin xyz="0 0 0.11" rpy="0 0 0"/>
<parent link="base_link"/>
<child link="head_link"/>
<axis xyz="0 0 1"/>
<limit effort="100" velocity="1.0" lower="-1.57" upper="1.57"/>
</joint>
- effort (required): An attribute for enforcing the maximum joint effort (|applied effort| < |effort|).
. revolute joint 또는 continuous joint인 경우 torque (Nȉm), prismatic joint인 경우 force (N)
- velocity (required): An attribute for enforcing the maximum joint velocity
. revolute joint 또는 continuous joint인 경우, 각속도 (radian/sec), prismatic joint인 경우, 속도 (meter/sec)
- lower (optional, defaults to 0): An attribute specifying the lower joint limit
. revolute joint인 경우 (radians), prismatic joint인 경우 (meters), continuous joint인 경우는 생략
- upper (optional, defaults to 0): An attribute specifying the upper joint limit
. revolute joint인 경우 (radians), prismatic joint인 경우 (meters), continuous joint인 경우는 생략

TF Frames
• Link는 각각 자신의 frame을 갖고 있고 이 frame은 visual geometric shape의 origin과는 독립적이다.
이를 확인하기 위해 “head_link”의 visual geometric shape의 원점을 (0, 0, 0.1)로 설정해보자.
<link name="head_link">

<origin rpy="0 0 0" xyz="0 0 0.1" />
<geometry>
<box size="0.1 0.1 0.1"/>
</geometry>
</visual>
</link>

parent_link frame
└─ joint origin (joint frame)
└─ child_link frame (joint origin과 동일)
(visual origin은 이 frame에서의 위치)

• “head_link”은 TF frame의 원점이 (0, 0, 0.11)이기 때문에 (joint에 정의된 origin을 확인하라) “base_link”로부터 (0, 0,
0.11) 떨어진 위치를 기준으로 z축으로 다시 0.1 만큼 떨어진 위치에 geometric shape이 위치하게 된다는 의미이다.

mimic Element
• URDF에서 Joint를 정의할 때 <mimic> element는 기존의 joint를 그대로 따라서 움직이는 joint일 경우 사
용된다.
• mimic된 joint는 별도의 motor없이 mimic한 joint를 그대로 따라 움직일 뿐이기 때문에 다음과 같이 joint
value가 자동적으로 계산된다.
value = multiplier * other_joint_value + offset
• mimic element의 속성
- joint (required): This specifies the name of the joint to mimic.
- multiplier (optional): Specifies the multiplicative factor in the formula above.
- offset (optional): Specifies the offset to add in the formula above. Defaults to 0 (radians for
revolute joints, meters for prismatic joints).

mimic Element
• URDF for cnubot
claw_a_r_link와 claw_b_r_link는 별도로 움직일 필요없이 단일 joint로 두개의 claw가 똑같이 움직이는게 더 효율적일
수 있다. 따라서 upper_arm_r_link_to_claw_B_r_link_joint는 별도로 움직임을 가질 필요없이
upper_arm_r_link_to_claw_A_r_link_joint를 mimic하도록 한다.
따라서 upper_arm_r_link_to_claw_B_r_link_joint 내용은 아래와 같이 변경될 수 있다.
<joint name="upper_arm_r_link_to_claw_b_r_link_joint" type="revolute">
<origin xyz="0 0 -0.065" rpy="-1.57 0 1.57"/>
<parent link="lower_arm_r_link"/>
<child link="claw_b_r_link"/>
<axis xyz="0 0 1"/>
<limit effort="100" velocity="1.0" lower="0.0" upper="0.0"/>
<mimic joint="upper_arm_r_link_to_claw_a_r_link_joint" multiplier="1.0" offset="0.0"/>
</joint>

만약 똑 같이 움직이지 않고 upper_arm_r_link_to_claw_B_r_link_joint를 좀 덜 움직이고 싶다면 multiplier를 변경한다.
multiplier="0.1"로 수정하고 Test 해본다.

XACRO (XML Macro)
• 간단한 로봇일지라도 크고 복잡한 URDF를 만들어야 하고 목적에 따라 매번 수정 변경해야 하는 일이 흔하게 발생한다.
• XACRO는 URDF를 프로그래밍처럼 작성할 수 있도록 지원한다.
robot descriptions을 좀 더 쉽게 이해할 수 있게 해주고, 좀 더 쉽게 유지보수 할 수 있도록 한다.
• XACRO 파일은 다음과 같이 XACRO description을 지정해주어야 한다.
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="cnubot">
...
</robot>

• XACRO elements
- Property: XACRO 파일 내에서 사용될 변수 지정 <xacro:property … /> 선언된 property는 ${property_name}으로 호출
- Argument: XACRO 파일이 호출될 때 전달될 입력 인자 지정 <xacro:arg … />
- Macro: 반복되는 구조의 재사용을 위한 함수 지정 <xacro:macro … > Block </xacro:macro>
- Conditional Block: 특정 조건 지정 (조건에 따라 블록을 활성화 또는 비활성화) <xacro:if … > Block </xacro:if>
- Math function: 수학함수 호출 ${pi}, ${sin}, ${sqrt}, …

Property in XACRO
• XACRO의 property element를 이용해서 hard-code된 상수값을 좀 더 유연하게 처리할 수가 있다.
• property가 설정이 되면 다음과 같이 다른 tag (<geometry> tag)에서 ${property_name}으로 값을 지정한다.
URDF
<link name=“base_link">
<visual>
<geometry>
<box size="0.1 0.1 0.1"/>
</geometry>
</visual>
<collision>
<geometry>
<box size="0.1 0.1 0.1"/>
</geometry>
</collision>
</link>

XACRO
<xacro:property name="body_width" value="0.1"/>
<xacro:property name="body_lenght" value="0.1"/>
<xacro:property name="body_height" value="0.1"/>
<link name="base_link">
<visual>
<geometry>
<box size="${body_width} ${body_lenght} ${body_height}"/>
</geometry>
</visual>
<collision>
<geometry>
<box size="${body_width} ${body_lenght} ${body_height}"/>
</geometry>
</collision>
</link>

Argument in XACRO
• XACRO의 argument는 xacro 파일 실행 시 외부에서 값을 전달받기 위한 입력변수이다.
- property가 파일 내 상수값이라면 argument는 파일 외부에서 주입되는 값이다.
<xacro:arg name="arg_name" default="default_value"/>
. name : argument 이름
. default : 외부에서 값을 안 줬을 때 사용할 기본값
• 사용 예
arg_example.xacro
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name=＂cnubot">
<xacro:arg name="box_size" default="0.1"/>
...

$ xacro arg_example.xacro box_size:=0.3

Macros in XACRO
• XACRO의 Macro는 robot model에 여러 번에 걸쳐 나타나는 URDF elements를 함수 형태로 정의하기 위해 사용된다.
• 예를 들어 6개의 다리를 가진 곤충로봇을 만든다고 하자. 다리를 하나만 정의해 두고 위치를 바꿔서 6번을 호출해서 6개
의 다리를 만들 수 있다. 바로 이러한 목적으로 사용되는 것이 Macro이다.
• 다음과 같이 macro를 만들고
<xacro:macro name="<name>" params="<param1 parma2:='0 0 0' …/>"
...
macro body
...
</xacro:macro>
• 다음과 같이 macro를 호출한다.
<xacro:<name> param1="<param1>" />

XACRO Conditional Block
• XACRO의 Conditional Block은 특정 조건에 따라 robot model의 일부를 선택적으로 포함 또는 제외할 수 있도록 한다.
• 다양한 application에 맞게 쉽게 customization 하거나, 로봇 구성에 따라 서로 다른 Gazebo plugin을 로드 한다던지 할
때 사용할 수 있다.
<xacro:if>, <xacro:unless> 와 같은 tag block으로 표현한다.
• 예를 들면, 특정 변수 (include_laser) 값이 True일 때만 Laser sensor를 구성한다고 하면 XACRO Conditional Block은
다음과 같다.
<xacro:arg name="include_laser" default="true"/>
<xacro:if value="${include_laser}">
<!-- Laser Sensor -->
<joint name="laser_sensor_joint" type="fixed">
...
</joint>
<link name="laser_sensor_link">
...
</link>
</xacro:if>
