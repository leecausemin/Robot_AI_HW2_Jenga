Rewards
• Sparse rewards: Goal을 정확히 달성했을 때만 보상을 주고, 그 외에는 보상이 0인 방식
• Dense rewards: 매 timestep마다 state나 action에 대해 지속적으로 보상을 주는 방식

Rewards
• Reward shaping의 예
Goal : +1
Avoid: -1
Each move: ??

Rewards in panda-gym
• panda-gym에서의 reward calculation: HER (Hindsight Experience Replay) 사용
- Dense reward: 물체의 위치 (또는 End Effector의 위치)와 목표 위치 간의 거리를 reward로 사용
- Sparse reward: Reward shaping 없이 성공(1)/실패(0)를 reward로 사용

Dense or Sparse Reward
def compute_reward(self, achieved_goal, desired_goal):
d = distance(achieved_goal, desired_goal)
if self.reward_type == "sparse":
return -np.array(d > self.distance_threshold)
else:
return -d

Done in panda-gym
• 에피소드가 종료되었는지를 나타내는 Boolean flag
. Terminated: 환경의 종료 조건(예: 목표 달성, 충돌)이 만족되어 에피소드가 끝났음을 의미
. Truncated: 환경에서 지정된 최대 스텝 수에 의해 중단되었음을 의미

Episodic task
Goal state: Object가 원하는 위치(goal position)로 옮겨진 상태
def is_success(self, achieved_goal, desired_goal):
d = distance(achieved_goal, desired_goal)
return np.array(d < self.distance_threshold)

Learning Algorithm
• Model architecture and learning algorithm
- On-policy Methods: 개념적으로 단순하고 직관적이며 탐색에 유리하지만, 데이터 효율성이 낮음
(A2C, TRPO, PPO)
- Off-policy Methods: 데이터 재사용으로 효율성이 높지만 알고리즘 구조와 구현이 복잡
(DQN, DDPG, TD3, SAC)
• Replay buffer
- Hindsight Experience Replay
- Prioritized replay buffer
• Evaluation
- success rates
- sample efficiency, computation cost, task throughput, robustness …

# PandaReach-v2

실습: set agent model
model = SAC(
policy="MultiInputPolicy", # policy model to use
env=env,
# environment to learn from
buffer_size=1000000,
# replay buffer size
learning_starts=1000,
# transitions before learning starts
batch_size=256,
# mini-batch size for each gradient update
policy_kwargs= {
# additional arguments to be passed to the policy
'net_arch': [64, 64],
'n_critics': 1,
}
learning_rate=0.001,
# learning rate for Adam optimizer
gamma=0.95,
# discount factor
tau=0.005,
# the soft update coefficient (polyak update)
replay_buffer_class=HerReplayBuffer,
replay_buffer_kwargs=dict(
n_sampled_goal=4,
goal_selection_strategy="future",
online_sampling=True,
max_episode_length=env._max_episode_steps,
)
verbose=1,
# the verbosity level: 0 no output, 1 info, 2 debug
seed=None,
# seed for the pseudo random generators
)

실습: train the model
model.learn(total_timesteps=20000)
model.save('panda_reach_sac')

실습: run the model
env = gym.make('PandaReach-v2', render_mode='human')
# load the model
model = SAC.load('panda_reach_sac', env=env)
# run
for i in range(20):
obs, _ = env.reset()
n_steps = 0
while True:
action, _state = model.predict(obs, deterministic=True)
obs, reward, terminated, truncated, info = env.step(action)
n_steps += 1
if terminated or truncated:
print('<Done> num of steps: {}'.format(n_steps))
time.sleep(1.0)
break
