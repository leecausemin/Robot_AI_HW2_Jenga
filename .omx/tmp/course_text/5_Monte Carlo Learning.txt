DP vs. RL
• Dynamic Programming
- Model-based (MDP 모델을 알고 있다고 가정)
- Each iteration updates every value function using full backup
- Evaluate V(𝑠) instead of Q(𝑠, 𝑎) because |{𝑠}| ≪ | 𝑠, 𝑎 |

DP

- For large problems, DP suppers the curse of dimensionality

• Reinforcement Learning
- Model-free (MDP 모델을 모른다고 가정)
- Each iteration updates some value function using sample backup

MC

(approximately solves Bellman optimality equation)
- Evaluate Q(𝑠, 𝑎) because V(𝑠) is not sufficient to determine optimal policy
- Breaking the curse of dimensionality through sampling

# Policy evaluation ----------------------------------------------------------# G ← 0 -------------------------------------------------------------G = 0
# Loop for each step of episode, t = T − 1, T − 2, ..., 0: ----------for t in reversed(range(len(episode))):
state, action, reward = episode[t]
# G ← γG + R_t+1 ------------------------------------------------G = gamma * G + reward
# Unless the pair St, At appears in S0, A0, ..., St−1, At−1: ----if not (state, action) in [(x[0], x[1]) for x in episode[:t]]:
# Append G to Returns(St, At)
Returns[(state, action)].append(G)
# Q(St, At) ← average(Returns(St, At)) -----------------------Q[state][action] = np.mean(Returns[(state, action)])
# Policy improvement ---------------------------------------------------------for s in range(n_states):
# epsilon-soft policy -----------------------------------------# A* <-- argmax Q(st, a)
best_action = np.argmax(Q[s])
# For all actions, apply ε-soft greedy actions ----------------action_prob = np.ones(n_actions) * (epsilon / n_actions)
action_prob[best_action] += (1.0 - epsilon)
policy[s] = action_prob

On-Policy vs. Off-Policy Learning
• On-Policy Learning: 현재의 policy에 따라 action을 선택하고, 그 결과를 바탕으로
policy를 업데이트하는 학습 방법
• 현재의 policy π에 따라 움직이면서 데이터를 얻고 이 policy를 평가하고 개선하는 방식
• π1, π2, π3, …에 대해 학습이 반복될 때 학습이 진행되는 바로 그 시점에서의 policy만을 이용하여 학습
데이터를 생성하기 때문에 학습이 끝난 뒤 데이터는 더 이상 쓸모가 없어지므로 폐기된다.

• Off-Policy Learning: action을 선택하기 위해 사용되는 policy (Behavior policy)와
실제 평가하고 개선하는 policy (Target policy)가 별도로 있는 학습 방법
• 2개의 policy를 가지며 behavior policy πβ 로 움직이면서 데이터를 얻고 target policy π를 평가
개선하는 방식
• behavior policy πβ 로 수집된 모든 데이터를 학습에 이용할 수 있으며, 데이터를 저장하기 위한
메모리를 필요로 한다.

몬테카를로 학습의 특징
• MDP 모델을 알 필요가 없다 (Model-Free)
State Transition과 Reward를 모르는 상태에서 샘플링을 기반으로 시도를 해보고 그 다음 상태
(Next State)가 어디로 갔는지 그 때 Reward가 어떤지를 확인

• 각 State의 State-value function가 다른 State들의 가치함수와 독립적으로 계산이 된다.
동적 프로그래밍의 경우는 현재 상태가 이후 상태들이 연관되어 계산을 했다.

• 각 State의 Value를 추정하는데 필요한 계산이 MDP 모델의 크기와 무관하다.
• 반드시 종료상태(Terminal State)가 있는 경우에만 적용 가능하며, 최적의 상태 가치를 얻
기 위해서는 그에 맞는 충분한 양의 탐색이 보장되어야 한다.
