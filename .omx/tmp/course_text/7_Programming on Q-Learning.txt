Types of Spaces in OpenAI Gym
• State(Observation) space and Action space
‒ Box: continuous space:
(ex) Box(low=-1, high=1, shape=(1,)) # [0.95]와 같이 -1과 1사이의 하나의 값으로 구성 (size가 1인 vector)
‒ Discrete: discrete space:
(ex) Discrete(4) # 0과 4 사이의 값 (0, 1, 2, 3)의 값으로 구성 (0과 같거나 큰 정수들의 집합을 대상으로 함)
‒ Dict: Dictionary of simple spaces:
(ex) “sensor_data”: Box(low, 0, high=100, shape=(3,)), “command”: Discrete(10)
# ‘sensor_data’라는 key에 0과 100사이의 3개의 값을 갖는 Box와 ‘commad‘라는 key에 0과 10사이의 정수값을 갖는 Discrete으로 구성

‒ Tuple: Tuple of simple spaces:
(ex) Tuple((Box(low=0, high=100, shape=(3,)), Discrete(10)))
# 0과 100사이의 3개의 값을 갖는 Box와 0과 10사이의 정수값을 갖는 Discrete으로 구성

‒ MultiBinary: “n-shaped” binary space:
(ex) MultiBinary(3) # [0, 1, 0] or [1, 1, 1] # 0 또는 1의 값을 갖는 3개의 값으로 구성
‒ MultiDiscrete: Multiple Discrete values
(ex) MultiDiscrete([3, 4]) # 첫번째 element는 (0, 1, 2), 두번째 element는 (0, 1, 2, 3)로 구성

Q-Learning
Algorithm

# loop for each episide
n_episodes = 1000
for _ in range(n_episodes):
# Initialize S (reset the environment)
state, _ = env.reset()
# loop for each step of episode
while True:
# choose A from S using policy derived from Q with e-greedy
random_number = np.random.random()
if random_number < epsilon:
action = env.action_space.sample()
else:
action = np.argmax(Q[state])
# take an action A, observe R, S'
next_state, reward, terminated, truncated, info = env.step(action)
done = terminated or truncated
# update Q(s,a)
td_target = reward + gamma * np.max(Q[next_state])
td_error = td_target - Q[state, action]
Q[state, action] = Q[state, action] + alpha * td_error
# S <- S’
state = next_state
# until S is terminal
if terminated or truncated: break
# decay epsilon
epsilon = max(epsilon - epsilon_decay, 0)

1. 보상 구조 개선:
• 각 행동마다 페널티 부여 (최소 step으로 목표에 도달하도록 학습)
• 구멍에 빠졌을 때 페널티 부여 (이를 통해 위험한 행동을 피하도록 학습)
2. Q-table 초기화 개선:
• 0 대신 작은 양수값(0.1~0.2)으로 초기화 (초기 탐색을 더 활발하게 만듦)
3. 최적의 Q-table 저장:
• 성공한 에피소드 중 가장 좋은 Q-table 저장 (학습이 끝난 후 최적의 Q-table 사용)
4. 최소 탐색 확률 유지:
• epsilon이 0.01 이하로 내려가지 않도록 설정 (지속적인 탐색 보장)
5. 최대 스텝 수 제한:
• max_steps = 100으로 제한 (무한 루프 방지 및 학습 효율성 향상)
